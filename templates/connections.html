💡 How Stateful Inspection Works: Unlike stateless firewalls that require separate rules for outgoing and incoming packets, a stateful firewall maintains a dynamically updated state table. When an outbound TCP handshake or UDP query is initiated and permitted, the kernel conntrack module registers the 5-tuple (Src IP, Dst IP, Src Port, Dst Port, Protocol). All corresponding return packets match the ct state established,related rule and are automatically permitted without needing manual reverse rules.
