🌐 How Real-World Web Filtering Works:
When you add a domain (e.g. example.com, instagram.com, or linkedin.com), the firewall intercepts traffic across Port 80 (HTTP) and Port 443 (HTTPS & QUIC):
  • HTTP Web Traffic (Port 80): Intercepted directly with the custom 🛡️ ACCESS RESTRICTED - 403 Forbidden block screen.
  • HTTPS Secure Traffic (Port 443): The TLS tunnel is rejected at the gateway (HTTP/1.1 403 Forbidden / ERR_TUNNEL_CONNECTION_FAILED), refusing the connection before any data is sent.
  • QUIC (UDP 443) Bypass Defense: Automatically disabled via system policy when Browser Protection is ON, forcing Chrome/Edge through the filter.
Toggling any rule to DISABLED restores access immediately!
