               INTERNET / HOST NETWORK (NAT)
                         |
                         | DHCP (e.g. ens33 / WAN)

                 |  FIREWALL VM  |

                 |  192.168.50.1 |
                 +-------+-------+
                         |
      === ISOLATED VIRTUAL LAN SWITCH (192.168.50.0/24) ===
