🌐 How Real-World Web Filtering Works

When you add a domain (e.g. example.com or instagram.com), the firewall resolves all its active destination IPv4 addresses (including www. aliases) and enforces strict Layer 7 & Layer 4 filtering:
  • HTTP Web Traffic (Port 80): Intercepted directly with the custom 🛡️ ACCESS RESTRICTED - 403 Forbidden block screen.
  • HTTPS Secure Traffic (Port 443): The TLS tunnel is rejected at the gateway (HTTP/1.1 403 Forbidden / ERR_TUNNEL_CONNECTION_FAILED), refusing the connection before any data is sent.
  • QUIC (UDP 443) Bypass Defense: Automatically disabled via system policy when Browser Protection is ON, forcing Chrome/Edge through the filter.
Toggling any rule to DISABLED restores access immediately!

💡 How Stateful Inspection Works: Unlike stateless firewalls that require separate rules for outgoing and incoming packets, a stateful firewall maintains a dynamically updated state table. When an outbound TCP handshake or UDP query is initiated and permitted, the kernel conntrack module registers the 5-tuple (Src IP, Dst IP, Src Port, Dst Port, Protocol). All corresponding return packets match the ct state established,related rule and are automatically permitted without needing manual reverse rules.

📄 Raw Compiled nftables Ruleset (nftables.conf)

#!/usr/sbin/nft -f
flush ruleset

table inet filter {
    set blocked_domains {
        type ipv4_addr;
        flags interval;
        elements = { 142.251.106.136, 142.251.106.190, 108.156.60.10, 157.240.22.35 };
    }

    chain input {
        type filter hook input priority 0; policy drop;
        iif "lo" accept
        ct state established,related accept
        tcp dport 22 accept
        tcp dport 5000 accept
        icmp type echo-request accept
    }

    chain forward {
        type filter hook forward priority 0; policy drop;
        ct state established,related accept
        ip daddr @blocked_domains drop
        ct state invalid drop
        ip saddr 0.0.0.0/0 ip daddr 0.0.0.0/0 udp dport 53 accept
        ip saddr 0.0.0.0/0 ip daddr 0.0.0.0/0 tcp dport 80 accept
        ip saddr 0.0.0.0/0 ip daddr 0.0.0.0/0 tcp dport 443 accept
    }
}
